A small Python web scraper I built while learning **web scraping**.

Right now, it takes product data from the Reliance Digital mobile collection and extracts:

* 📱 Product names
* 💰 Product prices
* 📄 Data from multiple pages

![Uploading Screenshot_20260823_000040.png…]()
## 🛠️ What I used

* Python 🐍
* Requests
* BeautifulSoup
* Git & GitHub

## 🚀 How it works

The program asks how many pages you want to scrape:

```text
how many page of data tho ? :
```

It then goes through those pages, finds the product information, and prints the names and prices.

## 📌 Current Status

This is **Version 1** of the project.

I'm still learning and improving it, so the scraper will probably get a lot better over time. 😭

Future improvements will include things like better data handling, cleaner output, and eventually more advanced scraping techniques.

## 🎯 Why I made this

Mostly to learn how real websites work behind the scenes and get better at Python web scraping.

Also... because building projects is way more fun than just watching tutorials. 😎
